# 06. UI

> 투명 프레임 없는 BrowserWindow. 펫 자체를 잡고 드래그, 모서리로 리사이즈. 우클릭으로 컨텍스트 메뉴. 좌하단에 HUD 텍스트. 위치/크기 자동 영속화.

## BrowserWindow 옵션

`electron/window.ts`:

```ts
new BrowserWindow({
  width, height,                  // snapshot.windowSize 에서 복원
  minWidth: 120, minHeight: 120,
  maxWidth: 600, maxHeight: 600,
  x, y,                           // snapshot.windowPos 에서 복원 (workArea 클램프)
  transparent: true,
  frame: false,
  resizable: true,
  alwaysOnTop: true,
  skipTaskbar: true,              // 윈도우 전환 UI 에서 빼기
  hasShadow: false,
  webPreferences: {
    preload, contextIsolation: true, nodeIntegration: false
  }
});
win.setAlwaysOnTop(true, 'screen-saver');
win.setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true });
```

`screen-saver` 레벨 — 다른 alwaysOnTop 앱보다도 위. `visibleOnFullScreen` — 다른 앱 풀스크린 모드에서도 보임.

## 드래그

`renderer/styles.css`:

```css
html, body, #root, .root { -webkit-app-region: drag; }
.pet { -webkit-app-region: drag; cursor: grab; }
.pet:active { cursor: grabbing; }
```

펫 본체 잡고 그냥 드래그 → 윈도우 이동. 빈 영역도 동일.

### 드래그 제외 (no-drag)

현재 HUD 와 컨텍스트 메뉴 트리거는 별도 처리:
- `.hud` 는 좌하단에 표시되는데 `-webkit-app-region: no-drag` 로 마킹돼 있어 텍스트 선택/클릭 우선.
- 우클릭은 OS 가 별도로 처리하므로 drag region 안에 있어도 contextmenu 이벤트 발생.

## 리사이즈

`resizable: true` + 범위 120~600px. macOS 는 frame 없어도 윈도우 모서리 픽셀에서 자동으로 리사이즈 커서를 띄움. 모서리에 정확히 마우스 올려야 잡힘 — 시각적인 그립 표시 없음.

리사이즈 동안 펫 스프라이트는 `width: 80%; height: 80%; object-fit: contain;` 으로 비례 스케일.

## 위치/크기 영속화

`electron/bootstrap.ts`:

```ts
win.on('moved',   () => pet.load({ ...pet.snapshot, windowPos:  {x, y} }));
win.on('resized', () => pet.load({ ...pet.snapshot, windowSize: {w, h} }));
```

`pet.load` → snapshot 이벤트 → debounced saver → pet-state.json 갱신. 다음 부팅에 복원.

부트 시 클램프: `safeX = clamp(0, workAreaSize.w - winW)`. 외장 모니터 분리 같은 케이스에서 화면 밖에 안 뜨게.

## 컨텍스트 메뉴

펫 우클릭 → 트레이와 동일한 메뉴 popup.

### 흐름

```
renderer 우클릭 (App.tsx onContextMenu)
  → window.pet.openMenu()         (preload contextBridge)
  → ipcRenderer.invoke('pet:openMenu')
  → ipcMain.handle:
      Menu.buildFromTemplate(menuTemplate()).popup({ window })
```

### 메뉴 템플릿 재사용

`electron/tray.ts` 의 `buildMenuTemplate(cb)` 가 menu items 배열을 반환. tray 와 ipc.ts 둘 다 이 함수를 호출해 동일한 메뉴 사용. 콜백 1세트 (`trayCb`) 로 두 진입점 모두 동작.

```
buildMenuTemplate(trayCb) ─┬─► createTray (메뉴바)
                          └─► wireIpc (펫 우클릭)
```

## 트레이 (메뉴바 아이콘)

`electron/tray.ts` 의 `createTray`:
- 18x18 컬러 비트맵 아이콘 (노란 알/병아리 형태 + 검은 눈).
- 좌클릭/우클릭 → 동일 contextMenu popup.
- macOS 메뉴바에 안 보이면 — [04-permissions-settings.md](./04-permissions-settings.md#macos-메뉴바-트레이-표시).

## HUD

`renderer/components/HUD.tsx` — 좌하단 monospace 3줄:

```
{stageName} · XP {N}{/M}
cond {N} · {mood}
{pct}%
```

- stageName: STAGES 에서 phase 매핑.
- next threshold 있으면 `XP / NEXT`, 없으면 `XP (max)`.
- pct: 다음 phase 까지 진척률.

스타일: `font: 10px monospace`, 흰 글자 + 검정 그림자. `-webkit-app-region: no-drag` 으로 클릭 가능.

## 펫 스프라이트 스케일

```css
.pet {
  width: 80%; height: 80%;
  display: flex; align-items: center; justify-content: center;
  filter: drop-shadow(0 4px 6px rgba(0,0,0,0.35));
}
.pet-sprite { width: 100%; height: 100%; object-fit: contain; }
```

윈도우가 작아져도 펫이 좁아진 컨테이너 안에서 비례 축소. drop-shadow 가 SVG 밖으로 살짝 나오므로 8% 여백이 보호 역할.

## 알려진 이슈

- **펫 본체가 drag region** 이라 좌클릭으로는 "쓰다듬기" 같은 인터랙션 못 함. 추가하려면 .pet 일부 영역 no-drag 로 빼고 그 위에서 click 이벤트 받기.
- **리사이즈 그립이 시각적으로 없음** — frame:false 때문. 우측 하단에 ⤡ 모양 SVG 핸들 그려넣으면 발견성 ↑.
- **dev 모드에서 stray Electron 프로세스** — `npm run dev` 종료 시 가끔 자식 Electron 한 개 남음 (vite-plugin-electron lifecycle 이슈). `kill -9` 또는 ABI 전환 시 신경 쓸 것.
