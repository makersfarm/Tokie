# 06. UI

> 투명 프레임 없는 BrowserWindow. 펫 자체를 잡고 드래그(5px threshold 로 클릭과 분리), 모서리로 리사이즈. 우클릭으로 컨텍스트 메뉴. 펫 좌클릭 → bounce + greeting 말풍선. 호버 → InfoBubble (XP/cond/today). idle 화면엔 stage badge + lifetime/threshold readout + 얇은 progress bar. 위치/크기 자동 영속화.

## BrowserWindow 옵션

`electron/window.ts`:

```ts
new BrowserWindow({
  width, height,                  // snapshot.windowSize 에서 복원
  minWidth: 120, minHeight: 120,
  maxWidth: 600, maxHeight: 600,
  x, y,                           // snapshot.windowPos 에서 복원 (workArea 클램프)
  transparent: true,
  frame: false,
  resizable: true,
  alwaysOnTop: true,
  skipTaskbar: true,              // 윈도우 전환 UI 에서 빼기
  hasShadow: false,
  webPreferences: {
    preload, contextIsolation: true, nodeIntegration: false
  }
});
win.setAlwaysOnTop(true, 'screen-saver');
win.setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true });
```

`screen-saver` 레벨 — 다른 alwaysOnTop 앱보다도 위. `visibleOnFullScreen` — 다른 앱 풀스크린 모드에서도 보임.

## 드래그

`renderer/styles.css`:

```css
html, body, #root, .root { -webkit-app-region: drag; }
.pet { -webkit-app-region: drag; cursor: grab; }
.pet:active { cursor: grabbing; }
```

펫 본체 잡고 그냥 드래그 → 윈도우 이동. 빈 영역도 동일.

### 드래그 제외 (no-drag)

다음 요소들은 `-webkit-app-region: no-drag` 로 마킹돼 있음:
- `.badge` — stage badge (펫 위쪽)
- `.progress` — progress bar (펫 아래쪽)
- `.token-today` — lifetime/threshold readout
- `.info-bubble` — hover info popup
- `.speech-bubble` — click/burst 말풍선
- `.burst` — EatingBurst 토큰 popup
- `.cutscene` — EvolveCutscene 오버레이
- `.stats` — Stats 윈도우 패널

우클릭은 OS 가 별도로 처리하므로 drag region 안에 있어도 contextmenu 이벤트 발생.

### Drag vs click threshold (펫 본체)

`renderer/App.tsx` 의 `onPointerDown`/`onPointerUp` 가 펫 sprite 를 감싸는 div 에 붙어 있음. mouse-down 좌표와 mouse-up 좌표 사이 거리가 **5px 이상이면 drag**, 미만이면 **click** 으로 해석. 펫 본체가 `-webkit-app-region: drag` 라서 OS 가 드래그를 처리하는 동시에 React 의 pointer 이벤트도 발생 — threshold 로 둘을 분리.

## 리사이즈

`resizable: true` + 범위 120~600px. macOS 는 frame 없어도 윈도우 모서리 픽셀에서 자동으로 리사이즈 커서를 띄움. 모서리에 정확히 마우스 올려야 잡힘 — 시각적인 그립 표시 없음.

리사이즈 동안 펫 스프라이트는 `width: 80%; height: 80%; object-fit: contain;` 으로 비례 스케일.

## 위치/크기 영속화

`electron/bootstrap.ts`:

```ts
win.on('moved',   () => pet.load({ ...pet.snapshot, windowPos:  {x, y} }));
win.on('resized', () => pet.load({ ...pet.snapshot, windowSize: {w, h} }));
```

`pet.load` → snapshot 이벤트 → debounced saver → pet-state.json 갱신. 다음 부팅에 복원.

부트 시 클램프: `safeX = clamp(0, workAreaSize.w - winW)`. 외장 모니터 분리 같은 케이스에서 화면 밖에 안 뜨게.

## 컨텍스트 메뉴

펫 우클릭 → 트레이와 동일한 메뉴 popup.

### 흐름

```
renderer 우클릭 (App.tsx onContextMenu)
  → window.pet.openMenu()         (preload contextBridge)
  → ipcRenderer.invoke('pet:openMenu')
  → ipcMain.handle:
      Menu.buildFromTemplate(menuTemplate()).popup({ window })
```

### 메뉴 템플릿 재사용

`electron/tray.ts` 의 `buildMenuTemplate(cb)` 가 menu items 배열을 반환. tray 와 ipc.ts 둘 다 이 함수를 호출해 동일한 메뉴 사용. 콜백 1세트 (`trayCb`) 로 두 진입점 모두 동작.

```
buildMenuTemplate(trayCb) ─┬─► createTray (메뉴바)
                          └─► wireIpc (펫 우클릭)
```

### 메뉴 항목

[04-permissions-settings.md](./04-permissions-settings.md#메뉴-항목) 참고.

## 트레이 (메뉴바 아이콘)

`electron/tray.ts` 의 `createTray`:
- 18x18 컬러 비트맵 아이콘 (노란 알/병아리 형태 + 검은 눈).
- 좌클릭/우클릭 → 동일 contextMenu popup.
- macOS 메뉴바에 안 보이면 — [04-permissions-settings.md](./04-permissions-settings.md#macos-메뉴바-트레이-표시).

## Ambient 정보 요소 (idle 시 항상)

펫 sprite 외에 idle 화면에 항상 떠있는 것들:

- **Stage badge** (`renderer/components/StageBadge.tsx`) — 펫 위쪽. 아이콘 + 이름. 윈도우 ≤ 140px 면 아이콘만.
- **Lifetime / threshold readout** (`renderer/App.tsx` 의 `.token-today`) — K/M 포맷 `{lifetimeXP} / {nextThreshold}`. K 1자리, M 2자리. Final phase 일 땐 Final 입성 임계값(3M) 을 분모로 표시.
- **Progress bar** (`renderer/components/PetProgressBar.tsx`) — 펫 하단 얇은 막대. lifetimeXP / nextThreshold 비율. mood 별 색감.
- **Mood emoji overlay** — happy/normal 일 땐 비어있음. sleepy 💤 / sad 😔 / feasting ✨ / curious ❔ 일 때 펫 우상단에.

기존 `HUD.tsx` 의 좌하단 3줄 텍스트는 **제거됨** (v2). 정보는 readout (항상) / InfoBubble (호버) / Stats 윈도우 (우클릭) 로 분산.

## Hover (호버 시)

`renderer/hooks/useHover.ts` — 150ms enter delay / 200ms leave delay. 펫 sprite 를 감싸는 div 에 `bind` 부착.

호버 시 `renderer/components/InfoBubble.tsx` 가 펫 우측에 표시 (윈도우 ≤ 160px 면 펫 아래 한 줄 compact 모드):

```
XP    12.3k / 300k
cond  78 · happy
today 4.2k
```

K/M 포맷. `useTokensToday` 훅이 `window.pet.getStats()` 를 30초 / PetEvent 마다 폴해서 `stats.today` (로컬 자정 이후 누적) 를 제공.

## Click / drag / burst speech

펫 좌클릭:
1. drag-vs-click threshold (5px) 통과.
2. 300ms cooldown 안 걸려 있어야 함.
3. bounce 애니메이션 0.4s + greeting SpeechBubble 0.8s (`pickGreeting` 풀에서 랜덤).

토큰 burst 자동 감지 (`core/feeding/burstDetector.ts` + `renderer/hooks/useBurstDetector.ts`): 5분 안 nutrition 합 ≥ 50k, 2분 cooldown. 발화 시 mood-flavored proactive SpeechBubble 2.5초 (`pickBurstLine(mood)`).

상세 동작은 [05-pet-design.md](./05-pet-design.md#transient-이펙트) 참고.

## 펫 스프라이트 스케일

```css
.pet {
  width: 80%; height: 80%;
  display: flex; align-items: center; justify-content: center;
  filter: drop-shadow(0 4px 6px rgba(0,0,0,0.35));
}
.pet-sprite { width: 100%; height: 100%; object-fit: contain; }
```

윈도우가 작아져도 펫이 좁아진 컨테이너 안에서 비례 축소. drop-shadow 가 SVG 밖으로 살짝 나오므로 8% 여백이 보호 역할.

## 알려진 이슈

- **리사이즈 그립이 시각적으로 없음** — frame:false 때문. 우측 하단에 ⤡ 모양 SVG 핸들 그려넣으면 발견성 ↑.
- **dev 모드에서 stray Electron 프로세스** — `npm run dev` 종료 시 가끔 자식 Electron 한 개 남음 (vite-plugin-electron lifecycle 이슈). `kill -9` 또는 ABI 전환 시 신경 쓸 것.
- **펫 본체가 drag region** 이라 OS 가 드래그를 가로채는데, React pointer 이벤트도 같이 발생. v2 에선 5px threshold 로 분리해서 클릭/드래그 둘 다 동작. threshold 만지려면 `App.tsx` 의 `CLICK_THRESHOLD_PX`.
